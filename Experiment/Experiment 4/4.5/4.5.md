# SQL Joins Practice – 3

## Question 1: Employee and Manager Names

Write an SQL query to display each employee's name along with their manager's name using the `employees` table. If an employee does not have a manager, display `NULL` as the manager's name.

### Expected Output

| Employee_Name | Manager_Name |
|---------------|--------------|
| John Doe | NULL |
| Jane Smith | John Doe |
| Peter Jones | John Doe |
| Mary Green | Peter Jones |
| Raj | Jane Smith |
