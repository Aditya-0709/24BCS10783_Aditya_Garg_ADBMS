# SQL LEFT JOIN

## Problem Statement

By default, SQL joins return only the rows that have matching values in both tables. To include all rows from the left table, even when there is no matching row in the right table, the **LEFT JOIN** operation is used.

### Example Syntax

```sql
SELECT *
FROM customer
LEFT JOIN order
ON customer.cust_id = order.cust_id;
```
