# Practice Problem 4 - American Cuisine Revenue Percentage

## Problem Statement

Write an SQL query to find what percentage of the **total revenue** (sum of all order prices) is contributed by **American** cuisine.

### Requirements
- Calculate the percentage of revenue generated by **American** cuisine.
- Alias the calculated column as **`American_Revenue`**.
- Round the final value to **2 decimal places**.

---

## Table: `Orders`

| Column | Data Type |
|---------|-----------|
| `order_id` | INT PRIMARY KEY |
| `item_name` | VARCHAR(255) |
| `cuisine` | VARCHAR(255) |
| `category` | VARCHAR(255) |
| `price` | DECIMAL(10,2) |
| `status` | VARCHAR(255) |

---

## Expected Output

| American_Revenue |
|-----------------:|
| 27.75 |

---

## Example

If the total revenue is **₹10,000** and American cuisine contributes **₹2,775**, then:

\[
\frac{2775}{10000} \times 100 = 27.75\%
\]

The output should be:

| American_Revenue |
|-----------------:|
| 27.75 |
